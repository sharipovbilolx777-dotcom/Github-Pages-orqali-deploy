# 🌐 GitHub Pages Orqali Veb-Sahifani Deploy Qilish

Ushbu loyiha yordamida yaratilgan HTML va CSS veb-sahifasini GitHub Pages xizmati orqali internet tarmoqlariga muvaffaqiyatli joylashtirish (deploy qilish) amaliyoti bajarildi.

---

## 🚀 Loyiha Maqsadi

* Statik veb-sahifalarni (HTML, CSS) GitHub repozitoriyasiga yuklash.
* GitHub Pages sozlamalarini to'g'ri sozlash orqali loyihani jonli (live) havola holatiga keltirish.
* Kodlarni masofaviy repozitoriyada (Remote Repository) boshqarish va yangilash.
